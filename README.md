# BL PROJECT IDLE

Jogo idle de futebol inspirado em Blue Lock.

## Publicar na Vercel

1. Em vercel.com, clique em **Add New > Project** e importe este repositório.
2. Não mude nada nas configurações: o `vercel.json` já diz que o site é a pasta `game/`, sem build.
3. Clique em **Deploy**.

A cada atualização da branch `main`, a Vercel publica de novo sozinha.
