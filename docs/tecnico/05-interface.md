## 5.1 Fluxo de telas

```
#landing (site, aberto ao carregar a página; showLanding)
  ├─ menu .ld-links: Início (#ldHome) · Sobre (#ldAbout) · Ranking (#ldRanking) · Wiki (#ldWiki) · Comunidade ("em breve")
  └─ "Minha conta" (.ld-acc, data-ld-auth="account") / "▶ Jogar" (#ldEnter, .ld-big) → #ldAuth (usuário e senha)
        └─ enterAccount(user)
             ├─ conta com save → G.load() → renderAll() → boot() → #app (jogo)
             └─ conta nova → #start (nome do time, Tag, função) → escolha do inicial (modal "Escolha seu jogador inicial") → boot()
```

## 5.3 Pop-up genérico

`#modal` > `.modal-box` > `.modal-h` (`#modalTitle`, `#modalClose`) + `#modalBody`. `openModal(title, html)` preenche, mostra e guarda `currentModal = title`; fecha com X, Esc ou clique fora (`closeModal`). Modal largo (`.modal-wide`, 1240 a 1440 px) apenas para os títulos "Expedição", "Chefes e Raids" e "Recompensa diária". `faseHome()` devolve o painel Fase e o Wildcard aos esconderijos antes de cada abertura/fechamento. Botões `data-open="<nome>"` chamam `MODALS[nome]()` (e `data-open="locked" data-what="..."` chama `MODALS.locked(what)`).

Fechar o modal "Pausa tática" retoma a partida (`G.resumePause`); fechar o "Vestiário" chama `G.vestEnd()`.
